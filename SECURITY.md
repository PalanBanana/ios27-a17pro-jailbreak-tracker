# Security Policy

## Supported versions

Only the `main` branch is maintained.

## Reporting a problem with this repository

Examples: a workflow that could expose secrets, a flaw in the validator, or personal data or device identifiers published by mistake.

Report these privately through this repository's **Security** tab using GitHub private vulnerability reporting. Do not open a public issue that contains sensitive details. Do not include device identifiers, credentials or personal data in any report. If personal data has been published, say so, and the maintainer will remove it from the affected revision.

## Reports about jailbreaks or exploits

This repository does not host exploit code, jailbreak tools or installation packages.

- If you have a vulnerability in Apple software, report it through Apple's published security reporting process.
- If someone asks you to install a jailbreak package, profile or IPA from a website or a private message, do not install it on any device you rely on. Report the source using the new-research issue template and choose 'Scam or fake-tool report'.

## Response

This is a maintainer-run project. We aim to acknowledge reports as quickly as we can, but response times are not guaranteed.
