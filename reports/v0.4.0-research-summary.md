# v0.4.0 research summary: cross-device audit and A17 Pro compatibility

**Status:** data as of 2026-11-12. Target: iPhone 15 Pro Max (A17 Pro, `iPhone16,2`), iOS 27.0.1, build 24A446. **Readiness: LEVEL 0 / NO-GO, unchanged.** This update audits external research and compares devices at the level of build metadata. It does not establish compatibility with the target.

## 1. What was done, and what was not

**Done**

- Audit of the SKVLENT iOS 27 research repository at commit [`73f7a57`](https://github.com/SKVLENT/iOS27-Research-Exploits/tree/73f7a579ce91): documents, licence, configurations, verdicts, superseded statements and contradictions. See [the audit](../research/skvlent-a19pro-research-audit.md).
- Metadata comparison of the A17 Pro, A19 Pro and A18 Pro packages: BuildManifests retrieved by range request, and component names compared. See [cross-device compatibility](../research/cross-device-compatibility.md).
- Static review of Erosion's documents, release notes, licence and metadata. See [the Erosion audit](../research/erosion-compatibility-audit.md) and [the risk assessment](erosion-daily-driver-risk.md).
- Ecosystem re-check of Dopamine, ElleKit, Procursus, Sileo and an upstream tracker. See [the ecosystem update](../research/jailbreak-ecosystem-update.md).
- An explanation of why a sandbox escape is not a jailbreak. See [the explanation](../research/sandbox-escape-vs-jailbreak.md).
- A per-finding compatibility matrix. See [the matrix](a17pro-compatibility-matrix.md).

**Not done, by design**

- No device was connected, updated, restored, rebooted or used for any test. No firmware was installed.
- No repository tool or bench was built or run. No probe, script or exploit from any external project was run.
- Erosion was not installed, its IPA was not downloaded, and no signing material was generated.
- No code-level or binary-level differencing was performed, consistent with the earlier decision. No binary was mapped to any advisory.
- The external projects' exploit-development material was not reproduced or analysed in depth. Only verdict labels and documented statements were recorded.

## 2. Main results

- **The SKVLENT repository states results on the A19 Pro (iPhone18,1, 27.0.1, 24A446), not on the A17 Pro.** Its stated results include a boundary crossing into other applications' containers and shared groups, container path disclosure with contents denied, denial-of-service effects, and an over-read in a networking process. Its stated limits are: kernel read and write not demonstrated, privilege escalation not demonstrated, and no jailbreak demonstrated. None of these is independently reproduced. None is verified for the A17 Pro.
- **Metadata differs by device in ways that matter for hypotheses.** The three packages name different monitor images (t8122, t8140, t8150), different GPU firmware (G16P, G17P, G18P), and different neural-engine firmware (h16, h17, h18). The A18 Pro and A19 Pro manifests list exclave-related components in each erase identity, and the A17 Pro manifest lists none in any identity. This is a package-level difference. Its reason and any behavioural effect are not established.
- **The A17 Pro's firmware package carries the same build number (24A446) as the A19 Pro's.** Their kernelcaches, monitors and firmware differ. Identical build numbers do not establish identical binaries.
- **Erosion declares support for iOS 27.0 to 27.2.1 and iOS 26.** It documents a sandbox escape, container browsing and modification, customisation and MobileGestalt tweaks. It documents no kernel access, bootstrap, root, persistence or SPTM bypass. It names no device or SoC. It warns that data may be lost. No independent device verification is in its repository.
- **Dopamine's current README** lists rootless ranges up to iOS 17.3.1 for arm64e devices, and no iOS 27 range. Its 3.0 release notes state that real-device SPTM support ends at iOS 17.3.1.

## 4. Contradictions recorded and not resolved

1. **SKVLENT's second-device build** is given as 27.2 (24B115) in one document and 27.2 (24B119) in others.
2. **SKVLENT's direction 03 on 27.2:** the README states that directions 01–07 reproduce on 27.2, while Apple's bulletin lists the CVE behind direction 03 as fixed in 27.2. Whether the 27.2 result reproduces the fixed behaviour is not stated.
3. **Erosion's maximum iOS 26 version:** 26.6.2 in the README; 26.7.2 in the description, the website and release 0.3.
4. **Erosion's latest commit** says "pretty sure 27.2.1 is supported", while the README lists 27.2.1 as supported. A commit states that the version check was disabled.
