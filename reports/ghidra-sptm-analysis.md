# Ghidra static analysis: SPTM image, iOS 27.0.1 (build 24A446)

**Status:** research summary, data as of 2026-11-12. Target: iPhone 15 Pro Max (A17 Pro, `iPhone16,2`), iOS 27.0.1, build 24A446. Offline, static, read-only. The SPTM image was taken from Apple's official firmware package. No device was connected or operated on. See [ghidra-kernel-analysis.md](ghidra-kernel-analysis.md) for method and limits, and [../research/sptm-evidence-audit.md](../research/sptm-evidence-audit.md) for the graded SPTM evidence.

This page records provenance, structure and analysis results. It does not describe how the SPTM enforces anything, and it does not assess any bypass.

## 3. Analysis result (verified, with limits)

- Automatic analysis succeeded and the program was saved, with **no analyser errors** logged.
- Functions recovered: 530. Of these, 529 have default names.
- Memory blocks: 22. Symbols: about 3,800, including labels generated by the analysis. Original names are essentially absent.
- Entry points: one.
- Reading of these results: the image is small, and its functions are almost entirely unnamed. Any statement about its behaviour would need function-level review, which this record does not contain.

## 4. Kernel-side evidence of SPTM interfaces (presence only)

The 24A446 kernelcache contains kernel log and format strings that refer to SPTM. They cover the SPTM version and load address, and a message about insufficient ASIDs supplied by SPTM. This shows that the kernel contains code paths that use an SPTM interface for address-space allocation. It does not show how those paths behave (C-083).

The kernelcache also has a `__DATA_SPTM` segment. In the kernelcache analysis, Ghidra recorded no code reference into that segment. The cause is not established (C-085). See [ghidra-kernel-analysis.md](ghidra-kernel-analysis.md), section 5a.

## 5. What this analysis does not establish

- The enforcement logic of the SPTM, or its handling of page tables.
- Any relationship between this image and the reported SPTM bypass. That report is second-hand and unverified (C-051). See [../research/sptm-evidence-audit.md](../research/sptm-evidence-audit.md).
- Whether the SPTM is active in the same way on the A17 Pro as on other devices. Apple states that SPTM is supported on A15-or-later and M2-or-later SoCs (C-013). Behaviour on this device is not established.
- Any vulnerability in the SPTM. No function was reviewed for correctness or security.
